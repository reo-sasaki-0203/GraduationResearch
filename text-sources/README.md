# Graduation Research

卒業研究用コードの置き場です。

## ASR

現在の研究本体です。Whisper系ASRにおけるpause、filler、attention、Encoder表現、認識誤りを扱います。詳細は[`ASR/README.md`](../ASR/index.html)を参照してください。

## SR

ReazonSpeech、ESPnet、未見データ評価などを試した以前の音声認識実験です。研究分野としては関連しますが、現在のpause・反復エラー解析からは直接参照していません。

`SRvenv`は大容量の仮想環境です。旧実験を再実行しないことが確定するまでは保管します。
