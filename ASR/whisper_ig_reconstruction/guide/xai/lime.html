LIME：入力の近くで簡単な説明モデルを作る

音声領域をいろいろ隠した入力に対するスコアを観測し、その周辺だけを説明する小さな線形モデルを当てはめます。今回の実験では未実装です。

1. 複雑なモデルを近くで近似する

Whisper全体を短い数式で表すのは難しくても、1つの音声の周辺なら「この区間を残すとスコアがどの程度高いか」を線形式で近似できる場合があります。これが局所的な代理モデルです。局所とは対象の近く、代理とは元のWhisperの代わりに説明する模型という意味です。

LIMEはその場の説明のために代理モデルを学習します。Whisperを再学習する方法ではありません。局所の近似がよく合っても、別の発話や雑音条件に通用する全体の規則とは限りません。LIME原論文を参照してください。

2. Whisperで比較する値

このページの比較対象は同じ固定文の出しやすさです。X は Whisper に入れる正規化済み log-Mel 特徴（128 メル帯域×T フレーム）、y は固定したトークン列です。モデルの重みと y を固定し、入力を変えたときだけスコアがどう変わるかを調べます。

F(X;y) = (1/L) Σ j∈J log p θ (y j | y <j , X)

θ は学習済みの重み、J は評価する本文トークンの位置集合、L=|J| はその個数です。各位置で同じ前のトークン y<j を Decoder に与える teacher forcing を使います。log は自然対数なので、単位を表すなら平均 nat/本文トークンです。値が大きい（通常は負なので0に近い）ほど、その固定文を出しやすいことを示します。音声→Encoder→Decoderのcross-attention→logits→log-softmax→対象トークンの選択→平均、という計算です。自由生成の文字列やCERとは別の値です。詳しくは評価指標を参照してください。

今回の主IGの y は雑音混合音声Bから元々生成した文です。正解文を固定する追加分析とは対象が異なります。手法間の比較では、この違いを混ぜないでください。

3. 解釈しやすい特徴と近傍を作る

まずM個の区間や時間×周波数ブロックを作ります。元の128×Tの特徴とは別に、z∈{0,1}Mという説明用表現を導入します。zi=1なら領域iを残し、0なら基準へ置き換えます。全領域を残す元入力はz=(1,…,1)です。写像hX(z)が実際にWhisperへ渡す特徴を作ります。

h X (z) f,t = z g(f,t) X f,t + (1−z g(f,t) )B f,t

fはメル帯域、tは時間、g(f,t)はそのセルの所属グループ番号です。Bは置き換え基準で、paddingは別扱いで固定します。領域が重複すると写像が曖昧になるため、その扱いを先に決めます。無音特徴、周辺平均、音声再構成などの選択は結果を変えます。特徴を隠す摂動は自然な音声と同じとは限りません。

4. 重み付き線形近似の数式

g(z) = β 0 + Σ i=1 M β i z i g* = arg min g∈G { Σ k=1 K π X (z (k) )[F(h X (z (k) );y)−g(z (k) )] 2 + Ω(g) } 例：π X (z)=exp(−D(z,1) 2 /σ 2 )
g^*=\underset{g\in G}{\arg\min}\left\{\sum_{k=1}^{K}\pi_X(z^{(k)})\left[F(h_X(z^{(k)});y)-g(z^{(k)})\right]^2+\Omega(g)\right\}
\pi_X(z)=\exp\!\left(-\frac{D(z,\mathbf1)^2}{\sigma^2}\right)

β0は切片、βiは残す特徴iの係数、Kは評価するマスク数、kはサンプル番号です。Gは候補の代理モデル集合、arg minは最も目的値を小さくするモデルを選ぶ操作です。πは元入力に近いサンプルを重くする係数、Dは元入力からの距離、σは近傍の広さです。Ωは係数を少数へ絞るなど複雑さへのペナルティで、具体的な正則化や選択方法を記録します。上のπは可能な設計例で、今回の実装済み設定ではありません。

二乗誤差の重み付き合計を減らすことと、簡単な説明を保つことを両立します。zは無次元なのでβの単位はスコアです。正のβは、その近傍の代理モデルにおいて領域を残すとFが高い傾向、負なら低い傾向です。IGの厳密な積分寄与やShapley値とは意味が異なります。

5. 説明用：2区間の線形模型

以下は説明用で、実測値ではありません。 観測値が全なし−4、aのみ−2、bのみ−3、両方−1だったとします。g(z)=−4+2za+zbなら全4点に一致し、係数はβa=2、βb=1です。この場合は簡単な線形説明で十分です。

一方、両方を残したときだけ−1、それ以外がすべて−4なら、aとbの組合せによる効果があります。相互作用項zazbを持たない線形gは全点へ正確に一致できません。近傍重みを変えると係数が変わり、最も近い領域を重くすれば全入力付近を優先して当てはめます。このため係数だけでなく、近似誤差を一緒に示す必要があります。

6. Whisperのどこを評価するか

各マスクで作ったhX(z)をEncoderの入力へ渡します。Encoderの畳み込み・self-attentionからDecoderのcross-attentionへ情報を渡し、固定したyのトークン確率を平均してFを得ます。LIMEはこの順伝播の入力とスコアだけを使うため、勾配や内部層の保存は必要ありません。

メル特徴上で隠す場合と、波形を編集してから特徴を作る場合は別の実験です。後者は音声再構成や前処理の影響を含みます。「Transformerのどの層を計算するのか」に対する答えは、選択層の値を重要度として取り出すのではなく、変えた入力でモデル全体を再計算し、その出力スコアを簡単な模型に近似する、ということです。

7. 計算量と信頼できる説明の確認

K個のマスクなら、おおむねK回のWhisper順伝播と小さな代理モデルの学習が必要です。モデルへのアクセスは固定スコアを返す関数で足り、内部勾配が使えない場合にも候補になります。Mが大きいほど十分なサンプル数が必要になり、互いに似たマスクばかりでは係数が不安定です。

学習に使っていないマスクで重み付き誤差を測る、元入力の予測Fとgの差を確認する、乱数seed・σ・領域幅を変えて係数の順位を比べる、といった検査が有効です。図が読みやすくても、代理モデルがWhisperへ十分一致しなければ説明の根拠が弱くなります。すべてのマスクを遠くまで広げると、「局所」の説明という目的から外れる可能性があります。

8. 何を調べられ、何は断定できないか

特定発話の粗い時間区間について、「この入力の近傍で残す／隠すとスコアがどう動くか」を短い説明にするのに適します。区間ごとの傾向を可視化して、モデルが雑音区間へ依存する可能性を探す用途もあります。しかし非線形な相互作用を直線へ押し込むため、係数を本来の計算機構や因果寄与と断定できません。

今回の1000件の保存結果にはLIMEはありません。導入する場合は対象文、領域分割、置換基準、距離、近傍幅、サンプル数、正則化、seedを決めて記録する必要があります。SHAPとの違いは、主に局所的な近似の目的と重み付けにあります。見た目が同じ係数表でも、定義が異なるため値を同一視しないでください。
