XAI：問いから手法を選ぶ

XAI（説明可能な人工知能）は、モデルのある判断について説明を作る方法です。重要度は対象と介入の定義で変わります。

この章の目次
  1. 1. 最初に固定する四つのこと
  2. 2. 代表手法の比較
  3. 3. 知りたいことと手法
  4. 4. 説明の検証

1. 最初に固定する四つのこと

①どの入力を説明するか、②どの出力スコアFを説明するか、③何を基準・置換値とするか、④どの単位（時間、周波数、内部特徴）に説明を集約するかを先に決めます。

本研究のIGは混合音のlog-Mel入力に対し、mixtureから生成した固定文の平均対数確率Fを説明します。Encoder最終層だけの大きさや、生成された文字列の編集距離を微分しているわけではありません。具体的な計算対象を参照してください。

2. 代表手法の比較

手法何を計算するか今回の扱い・注意
IG基準から入力までの変化を勾配で積分現在の主実験で実施。基準・対象文・収束誤差に依存
SHAP領域の組合せに対する貢献を配分未実装。背景・領域定義・計算量を決める

3. 知りたいことと手法

「入力のどこが固定文のスコアを支えるか」ならIG・Saliency、「その領域を消すと何が変わるか」ならOcclusion、「複数領域の組合せの寄与」ならSHAP、「この入力近傍を簡単なルールで説明したい」ならLIMEが候補です。内部の時間特徴を調べるGrad-CAMと、入力の時間×周波数に帰属するIGは、地図の軸が違います。

追加手法と選定上の注意、XAIを使わない分析も併せて読み、説明の見た目だけで性能や原因を断定しないでください。

4. 説明の検証

同じ対象スコア・同じ入力・同じ領域粒度で比較し、削除や保持によるスコア変化、ランダム対照、複数の基準、摂動の強さ、数値収束を確認します。観測された関連から、音声理解の普遍的な原因が証明されるわけではありません。これらの追加比較は提案であり、未実施の実験結果として扱いません。
