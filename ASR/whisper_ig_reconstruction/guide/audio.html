波形からメル特徴へ：音声の基礎

「音の場所」を調べるためには、音声を数値としてどの座標に並べるかを知る必要があります。時間の波形から、時間と周波数の表、位相まで順に進みます。

1. 波形とサンプリング：時間を測定点へ分ける

波形は、時間に沿って音の振動を並べたものです。デジタル音声は連続した振動を一定間隔で測った数列です。サンプリング周波数（Hz）は1秒あたりの測定点数で、今回は16,000Hzです。4秒なら64,000点あり、添字n=16,000は1秒の位置です。

t n = n / f s ;　s[n] は時刻 t n の波形値

nは0から始まるサンプル番号、fsはサンプリング周波数（1/秒）、tnは秒です。WAVの波形値はここでは正規化された数値で、マイクの校正なしに音圧Paや耳の大きさへ読み替えられません。複数チャンネルの平均、指定チャンネルの選択、必要なリサンプリングはload_audioで行います。

16kHzで表現できる最高周波数の目安は半分の8kHz（ナイキスト周波数）です。時間区間[a,b)秒を取るなら、基本的にサンプルa fsからb fsの直前までを選びます。実験は2〜30秒の発話を選び、長い発話を勝手に切り捨てません。

s[n]は時刻tnで記録した波形値です。時刻の単位は秒、nは0から数えるサンプル番号です。

2. 振幅、パワー、RMS：強さの比を測る準備

振幅は波の値や振れ幅です。正負の波をそのまま平均すると打ち消し合うため、強さの比較には二乗して平均した平均パワーを使います。RMSはその平方根で、波形と同じ数値尺度です。

P s = (1/N) ∑ n=0 N−1 s[n] 2 ;　RMS(s) = √P s
\operatorname{RMS}(s)=\sqrt{P_s}

Nは発話のサンプル数、s[n]は波形値、Psは波形値の二乗の尺度です。説明用：s=[1,−1,1,−1]なら平均波形は0ですがPs=1、RMS=1です。振幅を2倍にするとパワーは4倍です。これがSNRの雑音倍率で平方根が登場する理由です。

3. STFT：いつ、どの高さの成分があるか

発話全体を一度に周波数へ分けると、どの語がいつ現れたかが失われます。短時間フーリエ変換（STFT）は、短い窓を少しずつずらし、各窓の中の振動成分を調べる方法です。窓は端の急な切断による漏れを和らげる重みです。今回は周期的Hann窓です。

Z[k,t] = ∑ r=0 399 w[r] · s pad [160t + r − 200] · exp(−i 2πkr/400)

kは周波数ビン0〜200、tはフレーム番号、rは窓内のサンプル位置、wはHann窓、iは二乗すると−1になる虚数単位です。この式はcenter=Trueの窓中心を表す概念式で、範囲外は反射paddingで扱います。16kHzでは窓400点=25ms、hop160点=10ms、周波数ビン間隔40Hzです。窓が重なるので隣接フレームは独立した観測ではありません。

波形窓をずらす複素STFT
201 × 3001振幅を二乗周波数パワーの表

入力を30秒=480,000点へ右側ゼロpaddingしてからSTFTを計算し、モデル用には最後の1フレームを除いて3000フレームにします。逆変換用には3001フレームの複素数を保存します。使用版PyTorchの定義とMelTransform.analyzeに対応します。

4. 複素数、振幅、位相：同じ強さでも波の位置が違う

STFTの各セルZは複素数で、cosに似た成分とsinに似た成分をまとめています。Z=a+ibと書くと、aは実部、bは虚部です。振幅|Z|は成分の強さ、位相φはその成分の波が周期のどこにいるかです。

|Z| = √(a 2 + b 2 ) ;　φ = atan2(b,a) ;　Z = |Z| exp(iφ)
\varphi=\operatorname{atan2}(b,a)
Z=|Z|e^{\mathrm{i}\varphi}

atan2はaとbの符号も使って角度を決める関数です。角度はラジアンで、π=180度、2π=360度です。単一のsin波の位相をずらしても振幅や周波数は同じですが、他の波との重なり方は変わります。

説明用・音声や実験データは生成しません

青＝1つ目、橙＝2つ目、緑＝和。φ=180度ならsin(θ+π)=−sinθなので和は0です。数値でも、時刻θ=π/2の1と−1を足すと0です。

声や雑音は多数の周波数を含み、cleanの位相はmixtureの位相とは一般に違います。今回の再構成でmixtureの位相を使うことは、雑音の影響も一部引き継ぐことです。「パワーを変えればcleanの波形がそのまま戻る」とは言えません。

5. メル尺度と線形メルパワー

周波数をそのまま201個のビンで渡す代わりに、耳の周波数感覚を参考にしたメル尺度上の帯域へまとめます。メル・フィルタ行列Hは、各帯域へどのビンをどれだけ足すかを表す非負の重みです。今回のHはHugging FaceのSlaney尺度・正規化による128×201です。メル尺度には複数の慣習があるので、別のメル式を混ぜて同じ実装とは扱いません。

Q[k,t] = |Z[k,t]| 2 ;　P[m,t] = ∑ k=0 200 H[m,k] Q[k,t]
P[m,t]=\sum_{k=0}^{200}H[m,k]Q[k,t]

Qは周波数パワー（201×3000）、Pは線形メルパワー（128×3000）、mはメル帯域番号です。線形とは対数へ変換する前の値で、パワーを2倍にすると値も2倍になります。Hで201帯域から128帯域へ集約するため、元の周波数分布の情報が失われます。帯域ごとの混ぜ方が同じでも、元のQが一意とは限りません。

メルスペクトログラムは時間×メル帯域の強さの表の総称です。線形か対数かは別の話なので、「メル画像」とだけ言われたら、どの数値表現かを確認します。使用版HF前処理の行列をそのまま使っています。

6. log-MelとdB：モデル入力と評価用の表を分ける

弱い音と強い音が何桁も違うと、線形の表では弱い部分が読みにくくなります。対数は「何倍」を足し算の距離に置き換える尺度です。log10(10)=1、log10(100)=2です。今回のWhisper入力Xは次の変換です。

L = log 10 (max(P,10 −10 )) ;　X = (max(L, max(L)−8) + 4)/4
X=\frac{\max(L,\max(L)-8)+4}{4}

maxはセルごとの下限、max(L)は1音声の表全体の最大値です。ゼロの対数を避け、最大値から8桁より小さい値を下限へ切り上げてから尺度を変えます。説明用：最大P=1ならP=1のX=1、P=0.01のX=0.5、P=10−8のX=−1です。これは単純な音量正規化や物理音圧dBではありません。

D(P;P ref ) = 10 log 10 ( max(P,P floor ) / P ref )

評価・図には別のdB値Dを使います。Prefはその発話のcleanの有効区間の最大メルパワー、Pfloor=max(Pref×10−8,10−12)です。すべての比較音に同じ基準を使います。説明用：P=Prefなら0dB、0.01倍なら−20dB。画像の表示色の制限と、計算前の床値も区別します。詳しくはメル誤差の式へ。

「無音なら入力は0？」「基準は真っ黒？」「音声ごとに変わる？」はIG基準入力の詳しい説明、保存済み基準の可視化、入力への依存で確認できます。

7. 画像の読み方とpadding

横が時間、縦がメル帯域、色が強さです。1セルは「特定の短い時間における、ある周波数帯の集約値」で、独立した音の粒でも特定の文字でもありません。実音声の有効フレームは中心時刻160t/16000が発話終了前のものです。

30秒に満たない残りはpaddingです。今回のIG基準・マスク選択・評価の母数からは除外しますが、Whisperの全内部表現がpadding位置でゼロになるという意味ではありません。モデルは30秒の特徴を処理し、畳み込み・位置情報・attentionを通ります。有効マスクを渡した事実だけから、Encoderの全attentionがpaddingを完全に無視すると断定しません。

図を見るときは、①モデルの30秒入力か実発話区間か、②線形パワーかdBか、③計算上の目標かWAVから再計算した値か、④色の基準が共有か、を確認してください。再構成の章でこれらを結び付けます。
