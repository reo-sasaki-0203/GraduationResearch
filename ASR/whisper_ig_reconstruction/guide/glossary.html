1. 波形・サンプル・サンプリング周波数

波形は時刻ごとの振幅を並べた配列です。サンプルは配列の1点。16 kHzは1秒を16,000点で記録することです。振幅は本実装では無次元の浮動小数点数です。

計算式と具体例を読む →

2. 振幅・パワー・RMS

パワーは振幅を2乗した量。波形の平均パワーは2乗の平均、RMSはその平方根です。符号のある振幅を単純平均すると打ち消し合うので、音量比較には不向きです。

計算式と具体例を読む →

3. SNR・デシベル（dB）

SNRは信号パワーと雑音パワーの比を10 log₁₀で表したもの。10 dBならパワー比10倍です。振幅比に使う20 log₁₀と混同しません。

計算式と具体例を読む →

4. STFT・窓・ホップ

短時間フーリエ変換は短い区間ごとの周波数成分を求める操作。窓は端を滑らかにする重み、ホップは区間をずらす間隔です。

計算式と具体例を読む →

5. 複素数・位相・絶対値

複素数a+ibは二つの実数を持ちます。大きさ√(a²+b²)と角度（位相）でも表せます。位相は周期波のずれを示し、同じ大きさでも合成音が変わります。

計算式と具体例を読む →

6. Mel・スペクトログラム

スペクトログラムは時刻と周波数の強さの地図。Melは周波数のまとめ方で、低周波を細かく高周波を広く扱います。128 Melビンは128個の重なった帯域です。

計算式と具体例を読む →

7. 対数・自然対数・底・クリップ

log₁₀は10を何乗すると元の数になるか、ln（log）はe≈2.718を底にした対数。確率の対数には自然対数を使います。クリップは値を一定の範囲・下限へ抑える操作です。

計算式と具体例を読む →

8. テンソル・形状・軸

テンソルは多次元の数の配列。形状128×3000ならMel軸128、時間軸3000の行列です。どの軸を足すかによって結果の意味が変わります。

計算式と具体例を読む →

9. 行列・転置・ノルム

行列積は各行と列の積の和。Hᵀは行と列を交換した転置。ベクトルのL2ノルムは2乗和の平方根、行列のFrobeniusノルムは全要素の2乗和の平方根です。||H||₂は最大の伸縮率（スペクトルノルム）で、FISTAの刻みを決めます。

計算式と具体例を読む →

10. 微分・偏微分・勾配・積分

微分は微小な入力変化への出力の変化率。偏微分は他の変数を固定して一つだけ変えるもの。勾配は全変数の偏微分を並べた配列。積分は区間に沿った小さな寄与を足し合わせる操作です。

計算式と具体例を読む →

11. Attention・Q/K/V・ヘッド

Qは求める情報、Kは照合用の特徴、Vは集める内容。QとKの一致度を重みに変えてVを加重平均します。複数ヘッドは別の射影で同時にこの計算を行います。

計算式と具体例を読む →

12. トークン・語彙・EOS

トークンはモデルの文字列単位で、日本語1文字や1語とは限りません。語彙は対応するIDの一覧。EOSは生成の終了を示す特別なトークンです。

計算式と具体例を読む →

13. logit・softmax・条件付き確率

logitは各候補に対する確率化前の値。softmaxは指数化して全候補の和で割り、確率にします。p(yᵤ|y₍₍ᵤ₎,X)は入力Xとそれまでの文を与えたときの次トークンの確率です。

計算式と具体例を読む →

14. 自己回帰・teacher forcing

自己回帰生成は直前までのトークンから次を選びます。teacher forcingは評価する文を先に固定し、その文の直前までのトークンを入力して次の確率を測ります。

計算式と具体例を読む →

15. 基準入力・帰属・完全性

基準は比較の出発点。帰属はスコア差を入力要素へ配分する値。IGの完全性は帰属の総和が入力と基準のスコア差に一致する性質です。有限の数値計算では誤差を確認します。

計算式と具体例を読む →

今回の基準は有効区間−1.5、paddingは元の値を保持します。したがって配列全体は入力依存です。Whisper固有の普遍的な基準ではありません。実際の基準入力の画像も確認できます。

16. NNLS・FISTA・非負制約

NNLSは負にならない条件付きの最小二乗。FISTAは勾配更新と加速を組み合わせる反復計算法。圧縮されたMelパワーから周波数パワーの候補を求める際に使います。

計算式と具体例を読む →

17. CER・編集距離・置換/削除/挿入

編集距離は文字列を一致させる最小の編集回数。CERは置換・削除・挿入の総数を正解文字数で割った値。挿入が多いと100%を超えます。

計算式と具体例を読む →

18. 対照・対応あり・信頼区間・交絡

対照は比較の基準。対応あり比較は同じ音声の処理前後を比べます。信頼区間は推定の不確実性を示す範囲。交絡は複数の条件差が混ざり、原因を分離できない状態です。
