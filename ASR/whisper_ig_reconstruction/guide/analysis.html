XAI以外から研究を確かめる

重要度の図だけでは、音声を再構成する価値は判断できません。誤りの種類、対照条件、発話ごとの差、不確かさ、内部表現、聞こえ方を組み合わせて研究上の問いを調べます。

1. 現在の分析と、過去の研究・今後の提案

今回の1000件で実施済み：clear / mixture / reconstructedのCER・固定文スコア、再構成のみ・面積を合わせたrandom/energy対照、発話単位のbootstrap、雑音別・IG品質別の集計、発話長や保持面積とCER変化の探索的相関です。主モデルはWhisper large-v3です。

過去のpause研究：別プロジェクトのkotoba-whisper-v2.0・100発話では、発話内部へのpause挿入、線形probe、attention距離、cross-attention peak shift、occlusionを実施しました。これは今回の1000件の内部分析結果ではありません。

未実施の提案：今回のモデルのPCA・CKA・probe、系統的な閾値比較、同一発話への全雑音の割当、正式な主観評価です。この手引きのために新しい実験は実行していません。

基礎は音声、Whisper、Transformer、実装の流れは処理、指標は評価へ進んでください。

2. 「何文字間違えたか」から「どう間違えたか」へ

同じCERでも、語を聞き落とした場合と、同じ語を反復した場合では原因の候補が違います。正解と生成文を文字列として最小編集距離で対応させ、置換S・削除D・挿入Iに分けます。Sは文字の取り違え、Dは正解にある文字の欠落、Iは正解にない文字の追加です。

CER = (S + D + I) / N

Nは正規化した正解の文字数です。S/D/Iは回、CERは無次元です。説明用の例：正解「今日は雨」、出力「今日雨」ならN=4、D=1、CER=0.25です。反復による大量のIがあればCERは1を超えます。最適な対応が複数ある場合、誤り内訳は対応規則にも依存します。

次に、連続した語句の反復、終端欠落、長い無音での不要な文字生成をケースごとに確認します。生成上限到達を、正常な文章終了と区別する必要があります。終端記号がなく上限に達したことは打ち切りの手掛かりであり、単独では反復の原因を断定できません。

今回の補助認識sample_0400は、直接メル入力のrandom対照で正常な終端を得られなかった失敗として保存されています。主clear / mixture / reconstructedの認識失敗に置き換えて数えません。失敗例を除外するなら分母・除外理由を示し、成功例だけを全体の性能に見せないでください。

3. 同じ発話で比較し、不確かさを示す

短い簡単な発話と長い難しい発話を別々に比べると、方法の効果と発話の難しさが混ざります。そのため同じ発話iのBとCを組にします。誤り率ならC−Bは負が改善、メル誤差の既存ΔMAEならB−Cは正が改善です。符号を指標ごとに確認してください。

d i = CER C,i − CER B,i ,　d̄ = (1/n) Σ i=1…n d i
\overline d=\frac1n\sum_{i=1}^{n}d_i

iは発話番号、nは有効な組の数、d̄は平均差です。CERの差0.01は1パーセントポイントです。説明用の例：d=(-0.02,0,0.05)なら平均は0.01、1ポイント悪化です。一方で1件は改善しています。平均、改善・同じ・悪化の件数、中央値を併記すると片方だけでは隠れる性質が見えます。

bootstrapは「この発話集合の選ばれ方が変わったら平均差はどれほど動くか」を近似する方法です。既存実装はseed=42、2000反復です。各反復でn個の発話差から、同じ発話を再び選んでもよい復元抽出をn回行い、平均を計算します。

d̄ *(b) = (1/n) Σ j=1…n d J j,b ,　CI 95% = [Q 0.025 (d̄*), Q 0.975 (d̄*)]
\operatorname{CI}_{95\%}=[Q_{0.025}(\overline d^*),Q_{0.975}(\overline d^*)]

bは1～2000の反復、Jは1～nから抽出した発話番号、Qは標本平均の分位点です。既存コードはnumpy.quantileによるpercentile区間を保存します。トークンや隣接フレームを独立な100万標本のように数える処理ではありません。単一話者から複数話者への一般化や、データ選択の偏りまでこの区間が解決するわけではありません。

追加案：標準化した効果量dz=d̄/sdも使えます。sdは発話差の標本標準偏差です。ただしsd=0なら定義できません。今回保存済みの平均差・区間を、追加案の標準化効果量が既に計算済みであるかのように書かないでください。

4. 層別分析：どんな場合に悪化するか

層別は、雑音種類や発話長などに分けて傾向を見ることです。今回のexploratory.jsonには全件／IG品質合格、雑音別のΔFとΔCERのbootstrap、および発話長・保持面積・IG relative delta・ΔFとΔCERのSpearman相関が保存されています。相関は大小の順位の関連を測ります。

ρ s = corr(rank(x), rank(y))

x,yは同じ発話の2つの値、rankは同順位を平均順位にした並び順、corrはPearson相関です。範囲は−1～1です。値が0に近くても非単調な関係は残り得ます。今回の相関は探索的で、因果関係や多重比較を補正した有意性の主張ではありません。

white/pink/riverは10dB、traffic/kitchenは0dBであり、各雑音へ異なる200発話を割り当てています。したがって雑音別の平均差は、雑音の性質だけでなくSNRと発話集合の違いも含みます。「riverがtrafficより良いので雑音種類の効果が証明された」とは言えません。品質合格例だけの集計も、失敗しやすい入力を除いた集合の結果です。

追加案：同じ発話に全雑音・同じSNRを適用する設計なら、発話の違いを抑えて比較できます。これは未実施の新しい実験で、今回の保存結果を変更して実現するものではありません。

5. 対照条件で再構成と重要度選択を切り分ける

対照とは、確かめたい要素以外をできる限りそろえた比較相手です。今回、reconstruction_onlyはマスクせず逆変換だけを行います。random_matchedはIGと保持面積を合わせてランダムにセルを選び、energy_matchedは同じ面積で強い音のセルを残します。保持する面積が同じでも、IGの重要度総量・位置・領域の連続性は同じとは限りません。

d i,control = MAE control,i − MAE IG,i

正ならその発話でIGのほうがクリーン特徴に近いことを意味します。これにより、逆変換だけで変わったのか、単に面積を削った効果なのか、強い音を残すだけで足りるのかを調べます。既存paired_method_comparisons.jsonでは、CERや固定文スコアも同じ発話で比較しています。指標によって差の向きは違うのでキー名を確認します。

追加案：保持重要度の閾値、基準入力、位相の選び方、積分点数、領域の連続性を1つずつ変えるablation（要素を外す・変える比較）があります。95%だけの結果から95%が最適とは言えません。複数条件を試して最も良いものを選ぶ場合は、選定用と最終評価用の発話を分ける必要があります。

6. 内部表現：情報があることと、認識に使うこと

内部表現はEncoderの各時刻の特徴ベクトルです。PCAはばらつきの大きい方向へ座標を取り直して、2次元などで見る手法です。中心化した特徴行列H（行=対応したフレーム、列=特徴）に対し、HᵀHの固有ベクトルの上位k個Vkを使います。

Z = H V k

Zは低次元座標です。図で群が離れれば違いを可視化できますが、ばらつきの最大方向が認識に重要とは限りません。今回の1000件では未実施です。

線形probeは内部ベクトルhから、pauseか発話かなどのラベルを小さな線形モデルで読み出せるか調べます。

p(c|h) = softmax(Wh+b) c ,　L = −Σ i log p(y i |h i )
\mathcal L=-\sum_i\log p(y_i\mid h_i)

W,bはprobeだけの学習パラメータ、cは分類候補、yは正解ラベルです。Whisper自体を再学習する処理ではありません。過去のpause研究では実施済みですが、今回は未実施です。隣接フレームを無作為に学習／評価へ分けると同じ発話の情報が漏れるため、発話単位の分割が重要です。読み出せることは、Decoderがその情報を文字生成に使った証明ではありません。

CKAは2つの中心化した表現X∈ℝn×p,Y∈ℝn×qを比較する方法です。行は同じ発話の対応する時刻でなければなりません。

CKA(X,Y) = ‖XᵀY‖ F 2 / (‖XᵀX‖ F ‖YᵀY‖ F )

‖·‖Fは全要素の二乗和の平方根です。非零の分母では0～1の類似度で、1に近いほど表現の配置が似ています。ただし同じ転写や同じ原因を保証しません。今回への適用は未実施の提案です。CKA原論文を参照してください。

7. 時間対応と、聞こえ方を確認する

cross-attentionは出力トークンとEncoderの時刻の対応を調べる手掛かりです。ある層・head・トークンuに対する重みau,tの最大位置を求めます。

t̂ u = argmax t a u,t ,　shift u = Δt (t̂ u,changed − t̂ u,baseline )
\operatorname{shift}_u=\Delta t\,(\widehat t_{u,\mathrm{changed}}-\widehat t_{u,\mathrm{baseline}})

tはEncoderフレーム、Δtは1フレームの秒数、shiftの単位は秒です。説明用の例：20ms刻みでpeakが25フレーム遅れたら0.5秒です。過去のpause研究ではこの分析を行いました。今回は未実施です。異なるトークン列を同じ番号で比較すると別の文字を比較することになるため、固定した文をteacher forcingで評価するなどの対応付けが必要です。peakは公式な強制アライメントの正解時刻でも、寄与量でもありません。

主観評価は「聞き取りやすいか」「雑音が減ったか」「声が歪んだか」を人に確認する方法です。既存ページで聞けることと、正式な評価実験をしたことは別です。追加案：音量と再生機器をそろえ、clear / mixture / reconstructedの名称を隠して順番を無作為化し、聞き取り・雑音・歪みを別々の5段階尺度で回答してもらいます。参加者数、同じ音声の反復、評価者間のばらつきも記録します。平均評点MOS=(1/m)Σrjではjが評価者、mが回答数です。主観評点はCERや波形の近さの代替ではありません。

分類の境界にも注意してください。誤り集計やbootstrapは性能を調べる統計であり、特定予測を入力へ配分するXAIではありません。probeやattention可視化は広い意味で説明可能性に含められますが、この手引きでは内部診断としても扱います。対照や介入は研究設計であり、それだけであらゆる交絡が消えるわけではありません。XAIの比較と用語集へ進めます。
