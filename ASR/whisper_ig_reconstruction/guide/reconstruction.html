メルの表から音声へ：近似逆変換と位相

表の一部を削ることと、聞ける音声を作ることは別の計算です。情報が減ったメルの表から、どこまで戻せるかを具体的な逆問題として考えます。

  4. 4. パワーから振幅へ戻し、mixtureの位相と組み合わせる

1. なぜ、そのまま逆にたどれないのか

波形→STFT→パワー→メル→log-Melという変換には、情報を減らす段階があります。パワーにしたときに位相を失い、メルにしたときに201周波数ビンを128帯域へまとめます。さらに対数の下限で極小値を同じ値にしています。したがって、モデル入力のXだけを逆計算しても、元の音声が一意には定まりません。

今回はIGのマスクMを、対数前に保存したmixtureの線形メルパワーPへ掛けます。目標Ptarget=M⊙Pを「このメルの強さに近い音を作りたい」という条件として使います。モデル内部のEncoder hidden statesを音声へ変える処理ではありません。

2. 非負最小二乗：帯域に足し合わせた値を近づける

Hはメル・フィルタ行列（128×201）、Qは求めたい周波数パワー（201×T）、Ptargetは目標メルパワー（128×T）です。Tはここで逆変換するフレーム数です。Qには負のパワーを許さず、HQを目標へ近づけます。

min Q≥0 (1/2) ‖HQ−P target ‖ F 2

‖·‖F²は表の全セルを二乗して足した値、minはその値が小さくなるQを探すこと、Q≥0は各セルが非負という制約です。これがNNLS（non-negative least squares）です。「非負」はパワーの意味から必要になります。

説明用：H=[1,1]、目標が3ならq₁+q₂=3を満たす[1,2]も[2,1]もあり、逆が一意ではありません。目標の帯域ごとに独立に値を戻すのではなく、同じ周波数ビンが複数のメル帯域へ効く連立した問題を解きます。今回の解はcleanを教師にした学習結果ではありません。

3. 今回のFISTA：負を切り上げながら反復する

FISTAは、誤差が減る方向へ進む勾配更新に、前回の進み方を利用する加速を加えた反復法です。今回の実装は非負領域への射影（負の値を0へ戻すこと）を使います。一般的なFISTAには別の正則化もありますが、今回はこのNNLS問題です。

L=‖H‖ 2 2 ;　Q₀=max(HᵀP target /L,0), Z₀=Q₀, τ₀=1 Q r+1 =max(Z r −Hᵀ(HZ r −P target )/L,0) τ r+1 =(1+√(1+4τ r 2 ))/2 Z r+1 =Q r+1 +((τ r −1)/τ r+1 )(Q r+1 −Q r )
Z_0=Q_0,\qquad\tau_0=1
Q_{r+1}=\max\!\left(Z_r-\frac{H^\mathsf{T}(HZ_r-P_{\mathrm{target}})}{L},0\right)
\tau_{r+1}=\frac{1+\sqrt{1+4\tau_r^2}}2
Z_{r+1}=Q_{r+1}+\frac{\tau_r-1}{\tau_{r+1}}(Q_{r+1}-Q_r)

Hᵀは転置、‖H‖₂は行列の最大特異値、Lは更新を大きくしすぎないための尺度です。rは逆変換の反復番号、Zは加速した探索位置、τは加速係数です。この反復番号はIGの64点とは別です。

説明用：H=[1,1]ならL=2です。目標3、Z=[1,1]でHZ−P=−1。Hᵀ(−1)=[−1,−1]なので次のQ=[1.5,1.5]となり、合計3へ近づきます。実装は上のQ₀から初期化するので、この値は更新の説明用に別の探索位置を置いた例です。

最大200反復、反復途中で60秒超なら停止、相対更新量が10−5未満なら収束と記録します。時間制限の判定は反復境界です。有限反復なので最適解へ到達したとは限りません。Beck & Teboulleの原論文が反復法の背景、MelTransform.reconstructが今回の具体的な停止規則です。

4. パワーから振幅へ戻し、mixtureの位相と組み合わせる

Qは振幅の二乗なので平方根を取ります。今回新しく推定するのは周波数の強さで、位相は元のmixtureの複素STFTから借ります。

Ẑ[k,t] = √Q[k,t] · exp(i · angle(Z mixture [k,t]))

Ẑは再構成用の複素数の表、angleは位相を取り出す関数です。説明用：Q=4、mixture位相π/2なら振幅2、Ẑ=2iです。Qを1にするとiになりますが、cleanの位相が0だったとしても1へ戻るわけではありません。

位相の意味は波の重なりを操作する図で確認できます。mixture位相には雑音の影響が残り、同じ位相で小さくすることは、声と雑音の両方を変える場合があります。clean位相を使う方法や学習した音声生成器への置換は、今回実施していません。

5. iSTFT：重なった窓を整合させ、元の長さへ戻す

iSTFTは各フレームの周波数成分を時間の波へ戻し、重なる窓を重ね合わせて補正する逆短時間フーリエ変換です。窓とhopが不適切だと情報が欠けるため、元と同じHann窓・400点FFT・160点hopを使います。単純にフレームを横へつなぐ操作ではありません。

ŝ[n] ≈ (∑ t w[n−160t] · IFFT(Ẑ[:,t])[n−160t]) / (∑ t w[n−160t] 2 )

ŝは戻した波形、IFFTは各フレームを周波数から時間へ戻す変換です。式は窓の重なり補正を示す概念式で、centerの位置と境界処理は実装に従います。PyTorch 2.5.1の逆変換処理を参照できます。

今回、保存済みの完全な3001フレームを基礎にし、モデル用に落とした最後のSTFTフレームは元のmixtureを保持します。解くのは有効フレーム数+2まで（ただし最大3000フレーム）（窓が端に重なる部分）で、残りは元のスペクトルです。30秒全体でiSTFTしてから元のサンプル数へ切り戻します。ちょうど30秒の入力では、未マスクの最終端点の影響を記録します。

6. 計算上の目標と、実際にできた音は同じとは限らない

逆メルが近似であり、位相を固定し、STFTとして実現できる表に制約があるため、出来上がったCを再解析したメルは目標とずれることがあります。

P actual = H |STFT(C)| 2 ;　P actual ≠ P target の場合がある target_realized_relative_error = ‖P actual −P target ‖ F / (‖P target ‖ F +10 −15 )
P_{\mathrm{actual}}\not\equiv P_{\mathrm{target}}
e_{\mathrm{target\to realized}}=\frac{\|P_{\mathrm{actual}}-P_{\mathrm{target}}\|_F}{\|P_{\mathrm{target}}\|_F+10^{-15}}

この残差は有効フレームで測ります。目標メルを直接Whisperへ入れる補助認識と、CのWAVを通常の前処理へ通す認識は別物です。今回の主Cは後者です。sample_0400の補助失敗もdirect_target_melのrandom_matchedに限られ、clear / mixture / reconstructedの主評価は完了しています。

式のetarget→realizedは、保存キーtarget_realized_relative_errorを読みやすく短く表したものです。

7. 差分音声は、消えた雑音だけではない

同じサンプル位置・長さ・16kHzでC−BとB−Cを引き算して保存します。C−Bには、削れた声、位相や逆変換による変化、残った雑音などが混じります。真の雑音成分と同じではありません。

d[n]=C[n]−B[n] ;　B[n]+d[n]≈C[n] ;　B−C=−d
B[n]+d[n]\approx C[n],\qquad B-C=-d

浮動小数点の丸めを除いて加算で戻ることを検査します。FLOAT WAVの未調整差分を保持し、再生用にはclear / mixture / reconstructedと差分に共通の倍率を使います。差分だけを大きくして比較すると「たくさん雑音を除けた」と錯覚しやすいため、再生倍率にも注意します。評価の章へ進みましょう。
